SceneManager.cpp

This artifact is the SceneManager.cpp file from my 3D graphics project. It is the core class responsible for loading textures, defining materials, setting up lighting, and rendering an entire 3D scene composed of basic meshes. The original version was created in November 2023 for CS-330. The enhanced version was significantly refactored and improved in August 2026 as part of CS-499.

Why This Artifact Was Selected

I selected this artifact because it demonstrates my growth as a software developer. It started as a functional but repetitive and hardcoded implementation from an introductory graphics course and was refactored into a more professional and scalable system. The original version had over 350 lines of repetitive transformation, texture, material, and draw calls. The refactored version uses a data-driven approach that reduces code duplication while preserving visual quality.

Key Code Improvements

Scene Object Data Structure

  • Turned the hardcoded repetitive code into clean, structured data
  • Made the entire scene configurable and readable
  • Made it easier to modify without touching rendering logic
  • Better foundation for future features

Dynamic Object Creation

  • Replaced 6 nearly identical code blocks (80+ lines) with clean, compact data
  • Easier to add and remove objects or adjust positions/rotations
  • Centralized the data to make the intent very clear
  • More scalable — changes to multiple objects require almost no extra code

Data Driven Render Loop

  • Reduced the RenderScene function from ~350 lines to ~8 lines
  • Single source for rendering logic
  • Much easier to maintain and debug
  • Better enables future optimization work

O(1) Texture System

  • Changed texture lookup from slow linear search O(n) to faster hashmap lookup O(1)
  • Cleaner C++
  • Better performance when there are many objects and textures
  • Less error prone than manual array indexing

Reflection

Enhancing this artifact was a valuable learning experience. I learned the importance of data-driven design and how shifting from hardcoded logic to structured data can dramatically improve code flexibility and maintainability. One of the main challenges was refactoring the complex RenderScene function without breaking the visual output and preserving the precise positioning and rotation of all scene elements (especially the rocket, tower, and legs). It took several iterations to achieve both cleanliness and visual fidelity.

Course Outcomes Demonstrated

  • Application of advanced data structures
  • Implementation of software design best practices
  • Code refactoring and creation of clean, maintainable code
  • Graphics programming
