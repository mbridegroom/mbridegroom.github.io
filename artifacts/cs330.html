CS-330 • Computational Graphics and Visualization

SceneManager.cpp

Core class responsible for loading textures, defining materials, setting up lighting, and rendering a complete 3D scene. Original created November 2023; significantly refactored in August 2026 for CS-499.

Project Overview

The original implementation contained over 350 lines of repetitive transformation, texture, material, and draw calls inside the RenderScene function. The enhanced version uses a data-driven approach that reduces duplication while preserving visual quality and making the system far easier to modify and extend.

Software Design & Engineering

  • Transformed hardcoded repetitive code into clean structured data
  • Made the entire scene configurable and readable
  • Easier modification without touching rendering logic
  • Strong foundation for future features

Algorithms & Data Structures

  • Replaced 6 nearly identical code blocks (80+ lines) with compact data
  • Dynamic object creation – adding/removing objects requires almost no extra code
  • Data-driven render loop reduced RenderScene from ~350 lines to ~8 lines
  • Texture lookup changed from O(n) linear search to O(1) hashmap lookup

Learning & Reflection

This enhancement highlighted the power of data-driven design. Shifting from hardcoded logic to structured data dramatically improved flexibility and maintainability. The main challenge was refactoring the complex RenderScene function without breaking visual output or the precise positioning and rotation of scene elements (especially the rocket, tower, and legs). Several iterations were required to achieve both cleanliness and visual fidelity.

Course Outcomes Demonstrated

  • Application of advanced data structures
  • Implementation of software design best practices
  • Code refactoring and clean, maintainable code
  • Graphics programming proficiency
