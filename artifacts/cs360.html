DatabaseHelper.java

Core SQLite database helper for an Android calendar/events application. Original created during earlier mobile coursework; significantly enhanced in August 2026 for CS-499.

Project Overview

This class is responsible for creating and managing the users and events tables, handling user authentication, and performing CRUD operations on calendar events. The original version stored passwords in plain text and lacked proper data integrity and resource management. The enhanced version is a secure, professional, and robust database layer.

Software Design & Engineering

  • Refactored into a cleaner, more maintainable structure
  • Added comprehensive exception handling and logging
  • Centralized validation and resource management
  • Follows defensive programming and production-ready patterns

Security Improvements

  • Original stored passwords in plain text
  • Every password is now salted and hashed with SHA-256
  • If the database is compromised, passwords remain protected
  • Demonstrates a strong security-by-design mindset

Database Enhancements

  • Added foreign-key relationships between events and users
  • Added ON DELETE CASCADE for data integrity
  • Added indexes for faster queries by username and datetime
  • Schema is now more professional and production-ready

Resource Management & Input Validation

  • Original code often left Cursors open
  • Every Cursor is now safely closed in a finally block
  • Validates length and nulls before touching the database
  • Prevents common Android database crashes and leaks

Learning & Reflection

Working on this enhancement reinforced the importance of security by design. Small intentional changes—adding salt and hashing, enabling foreign keys, proper resource cleanup—dramatically raised the quality and professionalism of the database code. The main challenge was migrating from a plain-text password schema to a salted-hash approach without breaking existing authentication logic.

Course Outcomes Demonstrated

  • Secure database design
  • Proper data-access patterns
  • Application of software engineering best practices
  • Development of a security mindset
