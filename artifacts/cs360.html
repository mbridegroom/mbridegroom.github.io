DatabaseHelper.java

This artifact is the DatabaseHelper.java file from my final CS-360 Android project. It is the core SQLite database helper class responsible for creating and managing the users and events tables, handling user authentication, and performing CRUD operations on calendar events. The original version was created during earlier mobile development coursework. The enhanced version was significantly refactored and improved in August 2026 as part of CS-499.

Why This Artifact Was Selected

I selected this artifact because it demonstrates my growth as a software developer. It started as a functional but basic SQLite helper class that stored passwords in plain text and lacked proper data integrity and resource management. The enhanced version was refactored into a more secure, professional, and robust database layer. Specific components that showcase my skills include salted SHA-256 password hashing, foreign key constraints with cascading deletes, input validation, indexes, and timestamps.

Key Code Improvements

Secure Password Hashing

  • Original stored passwords in plain text
  • Now every password is salted and hashed with SHA-256
  • If the database is compromised, passwords remain protected
  • Demonstrates a strong security mindset required in professional software

Improved Database Schema

  • Added foreign key relationships between events and users
  • Added ON DELETE CASCADE for data integrity
  • Added an index for faster queries by username and datetime
  • Schema is now more professional and production ready

Proper Resource Management

  • Original code often left Cursors open
  • Now every Cursor is safely closed in a finally block
  • Added exception handling and logging
  • Prevents common Android database crashes and leaks

Input Validation

  • The original accepted any input
  • Now validates length and nulls before touching the database
  • Makes the API safer and reduces bad data in the tables
  • Follows defensive programming best practices

Reflection

Working on enhancing and refactoring this artifact was a valuable learning experience. It helped me learn the importance of security by design and how relatively small but intentional changes (adding salt and hashing, enabling foreign keys) can dramatically raise the quality and professionalism of database code. One of the main challenges was migrating from a plain-text password schema to a salted hash approach without breaking the existing authentication logic.

Course Outcomes Demonstrated

  • Secure database design
  • Proper data access patterns
  • Application of software engineering best practices
  • Development of a security mindset
