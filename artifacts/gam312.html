GAM-312 • Unreal Engine

Core Player Class (UE5 Survival Game)

Core class handling player movement, building, hunger, health, and UI integration in an Unreal Engine 5 survival game. Created around May 2026 and enhanced for the CS-499 portfolio.

Project Overview

This class manages complex player systems including building placement (line traces, grid snapping, overlap collision), resource interaction, and vital stats. The original version mixed multiple responsibilities inside large functions such as Tick() and FindObject(). The enhanced version applies clear separation of concerns and algorithmic refinements.

Software Design & Engineering

  • Moved complex building preview logic out of Tick()
  • Created dedicated functions with clear steps: line trace → grid snap → collision check
  • Broke FindObject() into smaller focused helpers
  • Centralized default values in the constructor
  • Improved null checks and overall readability

Algorithms & Data Structures

  • Refined line traces, sweeps, and grid-snapping logic
  • Separated resource harvesting logic from building logic
  • Replaced manual if-statements for stamina/health with proper clamping (0–100)
  • Reduced unnecessary work performed every frame

Learning & Reflection

The key lesson was the importance of separation of concerns. Functions such as Tick() and FindObject() were doing too much. Breaking them into smaller, focused functions improved readability and maintainability. A major challenge was ensuring changes remained compatible with existing classes and blueprints while still making the code more maintainable.

Course Outcomes Demonstrated

  • Outcome 3 – Algorithmic principles and efficient implementation
  • Outcome 4 – Software engineering and design (modularity, maintainability, clean code)
