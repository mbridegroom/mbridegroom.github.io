Professional Self-Assessment

A reflection on my growth throughout the Computer Science program at Southern New Hampshire University and how my skills prepare me for a professional career in software and game development.

Professional Self-Assessment

Completing the Computer Science program and developing my ePortfolio has helped me see how much I have grown as a developer. Being able to revisit my earlier work and improve it has shown me the importance of writing code that is efficient, secure, maintainable, and easier to understand. The program has also helped shape my goal of working in software or game development and prepared me for the expectations of a professional development environment.

Collaborating in a Team Environment

Throughout the program, especially during my Unreal Engine coursework, I worked with systems that had to function together. I learned the importance of modular design, clear communication, and version control when working on larger projects. These experiences helped me understand how my work can affect other parts of a project and the importance of keeping code organized.

Communicating with Stakeholders

I developed my communication skills through presentations, documentation, discussions, and code reviews. I learned how to explain not only what my code does, but also why I made certain technical decisions. Being able to explain technical information clearly is an important skill when working with developers, designers, and other stakeholders.

Data Structures and Algorithms

My coursework helped to strengthen my understanding of data structures and algorithms through C++, Unreal Engine, and other programming projects. I worked with arrays, vectors, maps, searching, line traces, collision detection, and other systems. These experiences taught me how choosing the right data structure or algorithm can improve performance while keeping code organized and readable.

Software Engineering

Software engineering has been an important part of my development throughout the program. I learned the value of modularity, separation of concerns, reducing duplicate code, debugging, and maintainability. I also learned that making code work is only part of development; it should also be organized in a way that makes future changes easier.

Databases and Security

My coursework gave me experience with database relationships, indexing, queries, data integrity, and resource management. I also developed a stronger understanding of security through input validation, authentication, and protecting user information. These experiences taught me to consider security and data integrity as part of the development process rather than something added later.

Professional Growth and Portfolio Overview

The program has helped me identify my strengths in problem solving, programming, software design, and game development. I enjoy creating interactive systems, but I also understand the importance of the software engineering principles behind them. My ePortfolio brings these skills together through three technical artifacts: CS-360 demonstrates database and security skills, CS-330 demonstrates data structures and software design, and GAM-312 demonstrates software engineering and game development.

Together, these artifacts help to show the range of my computer science skills and my growth throughout the program. They also demonstrate my ability to take existing work, identify areas for improvement, and make meaningful changes to its quality and maintainability.

Closing Reflection

The Computer Science program has given me a strong foundation for entering the field. I have developed technical skills while also learning how to communicate, collaborate, solve problems, and improve existing software. I believe these skills, along with my focus on game development, have prepared me to continue growing as a professional developer.
