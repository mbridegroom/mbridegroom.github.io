Professional Self-Assessment

A reflection on the technical skills, professional competencies, and personal growth developed throughout the Computer Science program at Southern New Hampshire University, with a focus on game development.

Introduction

Throughout my time in the Computer Science program at Southern New Hampshire University, I have grown from a student focused on completing individual assignments into a developer who understands how to design, secure, and maintain real software systems. The combination of core computer science courses and my game-development specialization has given me both the technical foundation and the practical experience needed to contribute in professional environments.

Collaborating in a Team Environment

Many of my projects required working with others through shared code repositories, coordinated design decisions, and integrating systems created by different team members. In my Unreal Engine coursework (GAM-312), I learned the importance of clear communication and modular design so that systems such as player movement, building placement, and UI could be developed in parallel without breaking each other. I also practiced using version control effectively and writing clear commit messages.

Communicating with Stakeholders

Through project presentations, code reviews, and written documentation, I have learned how to explain technical decisions to both technical and non-technical audiences. When enhancing my artifacts for the capstone, I focused on clearly documenting why specific improvements were made—whether adding salted password hashing for security or converting a hardcoded rendering system into a data-driven architecture.

Data Structures and Algorithms

My strongest demonstration of data structures and algorithms appears in the CS-330 SceneManager enhancement. The original implementation relied on repetitive, hardcoded logic. I refactored it into a data-driven system using structured objects and an efficient texture lookup (moving from O(n) linear search to O(1) hashmap access). In the GAM-312 project I also refined algorithmic systems such as line traces, grid snapping, and collision checks.

Software Engineering

Across all three capstone artifacts I focused heavily on software engineering best practices: separation of concerns, reducing code duplication, improving readability, and making systems easier to extend. In the Unreal player class I extracted complex logic out of the Tick function and broke large methods into smaller helpers. In the SceneManager I replaced hundreds of lines of repetitive code with a clean data-driven loop.

Databases

The CS-360 DatabaseHelper artifact provided direct experience designing and improving a relational database layer. I added foreign key constraints with cascading deletes, created indexes for performance, and ensured proper resource management of database cursors. These improvements moved the original implementation into a more professional and production-ready data access layer.

Security

Security was a major focus of my CS-360 enhancement. The original application stored passwords in plain text. I replaced that approach with salted SHA-256 hashing and added input validation. This work reinforced a security-by-design mindset: security should be an integral part of how systems are built from the beginning.

How the CS Program Prepared Me for Employment

The Computer Science program at SNHU combined strong theoretical foundations with repeated opportunities to apply those concepts in realistic projects. Courses in data structures, software engineering, databases, and security gave me the technical knowledge expected of junior developers. The game-development specialization allowed me to apply those same principles inside complex engines such as Unreal Engine 5. The capstone process of revisiting earlier work and deliberately improving it taught me how professional developers continuously refine their skills.

Game-Development Specialization

My specialization in game development has been one of the most valuable parts of the program. Working in Unreal Engine taught me how to design systems that must perform in real time, manage complex object interactions, and remain maintainable as features grow. These experiences gave me practical insight into the unique challenges of game programming while reinforcing the same software engineering principles used in other domains.

Closing Reflection

Completing this ePortfolio has given me a clear view of how far I have progressed. The ability to look back at earlier work, identify its shortcomings, and intentionally improve it is a skill I will carry into my professional career. I am confident that the combination of technical knowledge, practical experience, and a commitment to continuous improvement has prepared me to contribute effectively as a software developer.
