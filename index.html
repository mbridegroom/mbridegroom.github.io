Professional Self-Assessment

A reflection on my journey through the Computer Science program at Southern New Hampshire University and how the skills I developed prepare me for a professional career, with particular focus on game development.

Introduction

Completing the Computer Science program and developing this ePortfolio has allowed me to clearly see my growth as a developer. The process of revisiting earlier work, identifying weaknesses, and deliberately improving it has strengthened both my technical skills and my professional mindset. This self-assessment introduces the skills I have developed across collaboration, communication, software engineering, algorithms, databases, and security, and shows how the three enhanced artifacts work together to demonstrate those skills.

Collaborating in a Team Environment

Throughout the program I regularly worked in collaborative settings, particularly during my Unreal Engine coursework. In the GAM-312 survival game project, multiple systems (player movement, building placement, resource gathering, and UI) had to function together. I learned the importance of modular design and clear interfaces so that different parts of the project could be developed and tested independently without breaking existing functionality. Using version control and writing clear commit messages became essential practices for effective teamwork.

Communicating with Stakeholders

I have practiced communicating technical work to different audiences through project presentations, code reviews, and written documentation. When preparing the enhancements for this portfolio, I focused on clearly explaining not only what changed, but why the change improved the quality, security, or maintainability of the code. This ability to translate technical decisions into clear explanations is a skill I will continue to refine in professional environments.

Data Structures and Algorithms

My strongest work in this area appears in the CS-330 SceneManager enhancement. The original implementation used repetitive hardcoded logic. I refactored it into a data-driven design using structured objects and replaced a linear O(n) texture search with an O(1) hashmap lookup. In the GAM-312 project I also refined algorithmic systems such as line traces, grid snapping, and collision detection. These experiences reinforced the value of selecting appropriate data structures and keeping algorithms efficient and readable.

Software Engineering

Across all three artifacts I focused on core software engineering principles: separation of concerns, reduction of duplication, improved readability, and maintainability. In the Unreal player class I moved complex logic out of the Tick function and broke large methods into smaller, focused helpers. In the SceneManager I reduced a ~350-line render function to approximately eight lines through a data-driven approach. These changes demonstrate a professional approach to writing code that can grow and be maintained over time.

Databases

The CS-360 DatabaseHelper artifact provided direct experience improving a relational database layer. I added foreign key relationships with cascading deletes, created indexes for query performance, and implemented proper resource management for database cursors. These changes moved the original basic implementation toward a more production-ready data access layer and strengthened my understanding of data integrity and efficient database design.

Security

Security was a central focus of the CS-360 enhancement. The original code stored passwords in plain text. I replaced that approach with salted SHA-256 hashing and added input validation. This work developed a security-by-design mindset: security considerations should be built into the architecture from the beginning rather than added later. It also demonstrated how relatively small, intentional changes can significantly improve the protection of user data.

How the Artifacts Work Together

The three artifacts in this portfolio complement one another. The CS-360 project demonstrates secure database design and defensive programming. The CS-330 project shows advanced use of data structures and clean software architecture in a graphics context. The GAM-312 project applies software engineering and algorithmic thinking inside a real-time game engine. Together they illustrate growth across software design, algorithms, databases, and security while highlighting my specialization in game development.

Preparation for Employment & Closing Reflection

The Computer Science program combined theoretical foundations with repeated practical application. The process of enhancing earlier work for this capstone taught me how professional developers continuously improve code quality, security, and maintainability. I am confident that the combination of technical skills, a security mindset, and experience with both traditional software systems and game engines has prepared me to contribute effectively in a professional software development role.
