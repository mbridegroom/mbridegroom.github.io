Professional Self-Assessment

My Growth as a Computer Science Professional

Completing the Computer Science program at Southern New Hampshire University has given me the opportunity to build a broad foundation in software development while also allowing me to focus on my interest in game development. Throughout the program, I have worked with multiple programming languages, development environments, databases, software engineering practices, algorithms, and security concepts. The ePortfolio represents the growth of those skills and provides examples of how I have applied them to practical projects.

One of my strengths is my ability to approach software development as an iterative process. Rather than viewing a project as finished once it works, I have learned to examine the structure, efficiency, maintainability, and usability of my code. Projects such as my computational graphics work gave me experience improving existing code instead of simply creating something from scratch. This helped me understand the importance of writing software that can be maintained and expanded over time.

Collaboration and Communication

The Computer Science program also strengthened my ability to communicate technical information to different audiences. Through coursework and project documentation, I learned how important it is to explain technical decisions clearly instead of assuming that everyone reviewing a project has the same technical background. Working through software development processes also helped me understand how developers communicate with teammates, stakeholders, and other audiences throughout the development lifecycle.

Data Structures and Algorithms

My coursework in data structures and algorithms taught me to think about more than whether a program produces the correct result. I learned to consider how data is stored, accessed, and processed and how those choices affect the efficiency of a program. I applied these concepts when improving existing projects by replacing inefficient approaches with more appropriate data structures and algorithms.

Software Engineering

Software engineering has been one of the most important areas of growth throughout my program. I learned the importance of organization, modularity, maintainability, testing, documentation, and designing software around future requirements. My enhancements demonstrate that understanding by taking functional projects and improving their underlying structure rather than focusing only on their appearance or immediate functionality.

Databases

My database coursework provided experience working with structured data and connecting applications to persistent storage. I learned how database design affects the way applications retrieve, modify, and organize information. These skills became especially useful when developing applications that needed to communicate between the user interface, application logic, and database layer.

Security

Security has also become an important part of how I think about software. Secure coding coursework helped me recognize that vulnerabilities should be considered during the design process rather than after an application has already been completed. I learned to consider issues such as input validation, authentication, authorization, data protection, and potential ways an application could be exploited.

Professional Goals

My primary professional goal is to work in the computer science field with a focus on game development and interactive software. My experience with C++, Unreal Engine, graphics programming, software architecture, and application development has helped me build toward that goal. At the same time, my broader coursework has given me skills that apply beyond game development, including database development, algorithms, software engineering, testing, and security.

Portfolio Overview

The artifacts included in this portfolio demonstrate different parts of that development. Together, they show my ability to analyze existing software, identify areas for improvement, implement enhancements, and communicate the reasoning behind those changes. The portfolio also demonstrates how software design, algorithms and data structures, databases, and security concepts work together when developing complete computing solutions.
